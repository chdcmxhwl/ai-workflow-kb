# AI 工作流编排平台 · 演示知识库

本仓库存放「可视化智能工作流编排平台」期中答辩所用的知识库材料，共 8 份中文文档。这些材料同时导入本机应用的知识库，供工作流中的「知识检索」节点与大语言模型节点调用，用于说明检索如何把外部资料带进模型回答。

## 资料分组

**1. 课程课件（`01-课程课件/`）**。三份面向课程场景的讲义，分别讲 HDFS 块机制与块大小选择、冯·诺依曼体系结构，以及大数据技术期中复习提纲的正文节选。课堂测验出卷与课件问答助手两套模板的默认输入指向「冯·诺依曼体系结构」，由这一组承接。

**2. 本平台文档（`02-本平台文档/`）**。一份平台自述，依据项目 README 与本地源码整理，说明 22 种节点的五层分组、变量系统、模型执行层、知识库分块与 BM25 检索机制、问答路由、场景模板以及本地 SQLite 存储。

**3. 同类平台资料（`03-同类平台资料/`）**。四份依据 GitHub 原始 README 整理的中文材料，分别介绍 Dify、n8n、LangGraph 与 Coze Studio。用于说明节点式可视化编排是同类平台共有的做法，以及各平台在运行形态与检索实现上的差别。

## 资料来源

Dify、n8n、LangGraph、Coze Studio 四份材料的原始来源为各自的 GitHub 仓库 README，抓取日期为 2026 年 11 月 12 日，整理时保留原项目的术语与能力划分。平台自述依据本项目 README 与 `KnowledgeService.ts`、`database.ts` 等源码。每份文档开头均标注了具体来源。

## 检索机制

应用采用零依赖的 BM25 词法检索，不依赖向量模型与网络。导入后按段落贪心合并分块，每块目标长度 500 个中文字符，相邻块保留 60 字重叠；中文同时切出单字与二字组，默认返回最相关的 5 块。词法检索依赖字面重合，因此主题集中的短文档比内容混杂的长文档更容易被准确召回。

## 可检索的问题示例

「22 种节点 基础编排 模型与文档 流程控制」「BM25 词法检索 中文二字组 分块 重叠」「Dify 的 RAG 管线 文档摄入 检索」「n8n 的 fair-code 许可」「LangGraph 持久化执行 人在回路」「Coze Studio 四项核心技术」「冯·诺依曼体系结构 的主要知识点」。知识库未收录的主题检索得分明显偏低，可据此区分「有资料」与「没有资料」。
